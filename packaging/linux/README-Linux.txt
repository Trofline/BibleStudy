BibleStudy für Linux / BibleStudy for Linux
============================================

DEUTSCH
-------
1. Entpacken:  tar -xzf BibleStudy-Linux-x64-<Version>.tar.gz    (oder im Dateimanager "Hier entpacken")
2. In den Ordner wechseln:  cd BibleStudy
3. Starten:  ./BibleStudy
   Falls "Keine Berechtigung" erscheint:  chmod +x BibleStudy mcp/BibleStudy.Mcp   und danach noch einmal ./BibleStudy
Deine Daten liegen in ~/.local/share/BibleStudy, getrennt vom Programm. Das Programm aktualisiert sich unter Linux nicht selbst:
Neues Paket von https://github.com/Trofline/BibleStudy/releases laden und den alten Ordner ersetzen.
Dieses Paket ist auf Windows gebaut und nicht auf jedem System getestet. Bei Problemen bitte ein Issue auf GitHub öffnen und die
Meldung aus dem Terminal dazuschreiben.

ENGLISH
-------
1. Unpack:  tar -xzf BibleStudy-Linux-x64-<version>.tar.gz    (or "Extract here" in your file manager)
2. Change into the folder:  cd BibleStudy
3. Start:  ./BibleStudy
   If you get "Permission denied":  chmod +x BibleStudy mcp/BibleStudy.Mcp   and run ./BibleStudy again
Your data is stored in ~/.local/share/BibleStudy, separate from the program. The program does not update itself on Linux:
download the new package from https://github.com/Trofline/BibleStudy/releases and replace the old folder.
This package is built on Windows and not tested on every system. If something goes wrong, please open an issue on GitHub and add the
message from the terminal.
