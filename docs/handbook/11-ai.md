# 11. AI Assistant, MCP and Ollama

AI is **optional** in the program. Everything else works without it.

## 11.1 The "Claude" tab

Right rail → **AI → Claude**. The window uses your locally installed **Claude Code app with your login**: no API key, and the program doesn't incur any API costs. Claude sees **only this program's Bible tools**.

With these tools, Claude can, for example, read the Bible, look up cross-references and Strong's numbers, and control the program (display, highlight, notes, queue, to-dos).

### Conversations

Several conversations run side by side, each with its own history. **＋ New conversation** opens another one; the ✕ in the tab closes one.

### The instruction

Under *Settings → AI* you'll find the **instruction for Claude**, which is placed in front of every conversation. You can change it freely; *Restore default text* brings back the original. Among other things, the default text requires: **Scripture explains Scripture** (Tota Scriptura), clear passages interpret unclear ones, church-historical or extra-biblical information only as background, and, where there are several legitimate interpretations, the pros and cons each argued from Scripture.

## 11.2 Ollama: local AI

If you don't want to send anything to an outside service, use **Ollama**: the model runs on your computer, and everything stays there. Under *Settings → AI*, choose *Ollama* instead of *Claude Code* and click *Find Ollama*.

## 11.3 Translating word meanings

The option *Translate word meanings into my language* has the AI translate the dictionary meanings (in English) into your language. The result is saved, so nothing gets translated twice. These are AI translations; double-check important passages.

## 11.4 MCP server for other programs

The program comes with an **MCP server**. This lets another program (for example Claude Code) operate BibleStudy. *Settings → AI → MCP server for other programs* shows the command to enter; **Copy command** puts it on the clipboard.

The server talks to a local interface of the program, which is protected by a token.

## 11.5 Important notes on AI

- AI can be wrong, even with Bible passages. **Check against the text.**
- AI doesn't replace reading Scripture. It's a tool for finding passages, words and connections.
- Questions that work well: "Where else does this original-language word occur, and how is it translated?", "Summarize the cross-references to this verse", "What interpretations exist for this passage, and what speaks in favor of each?"
