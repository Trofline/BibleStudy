# 18. Glossary, Sources and Licenses

## 18.1 Glossary

| Term | Meaning |
|---|---|
| **Advanced / Easy** | full range of features / streamlined interface |
| **Accent color** | the program's main color; the main column in parallel mode uses it |
| **Aorist** | Greek tense for a simple, single-point action |
| **BDB** | Brown-Driver-Briggs, Hebrew lexicon (1906, public domain) |
| **Backlink** | a reverse link: a document that points to the current one |
| **Base form (lemma)** | the dictionary form of a word, for example "go" for "went" |
| **Original text** | the Hebrew and Greek source text |
| **Cantillation** | Hebrew accent marks that also indicate stress |
| **Category** | colored chip on a document, internally a tag `kat:Name` |
| **Concordance** | an index of all passages where a word occurs |
| **Layout** | a saved window arrangement |
| **Bookmarks** | a remembered verse without a note (formerly "watch list") |
| **LSJ** | Liddell-Scott-Jones, comprehensive Greek lexicon |
| **MCP** | Model Context Protocol, an interface that lets AI programs operate BibleStudy |
| **Morphology** | the grammatical form of a word (tense, case, person …) |
| **Ollama** | a program for running AI models locally |
| **Parallel** | several translations side by side |
| **Plugin** | an extension that runs as its own process |
| **Cross reference** | a connection between verses |
| **Scripture alone** | guiding principle: the Bible text comes first |
| **Strong's number** | number of a Hebrew (H) or Greek (G) word according to James Strong |
| **Syntax** | sentence structure with roles such as Subject, verb, Object |
| **Tag** | a keyword on a highlight or a document |
| **To-do** | a task for your study, with sub-to-dos, a date and a verse |
| **Vault** | a folder (a single file) holding everything personal in a project |
| **Word study** | clicking a word with a Strong's number to see the original-text word and its occurrences |

## 18.2 Sources

The program contains no Bible texts. Everything is loaded from the original source when needed and is listed with its origin and license under *Settings → Sources and licenses …*. The complete list is in [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md). Examples of sources mentioned in the manual:

- **Brown-Driver-Briggs** (1906, public domain), digitized by the Open Scriptures Hebrew Lexicon Project, CC BY 4.0
- **Liddell-Scott-Jones**, edited by Tyndale House Cambridge (STEPBible), CC BY 4.0
- **Easton's Bible Dictionary** via Theographic
- **openthesaurus.de**, CC BY-SA 4.0 (German synonyms)

Principle for new sources: only public domain or freely licensed (CC BY, CC BY-SA, CC0) from well-known providers, nothing restricted to non-commercial use and nothing with an unclear license.
