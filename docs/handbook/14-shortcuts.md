# 14. Keyboard shortcuts

All shortcuts in the first table can be changed (*Settings → Keyboard shortcuts* or the *Keyboard shortcuts* button at the top). The table shows the **default assignment**. On a Mac, "Ctrl" usually means the Command key, depending on your system settings.

## 14.1 Changeable shortcuts

| Shortcut | Effect |
|---|---|
| Ctrl+K | Go to passage or search |
| Ctrl+F | Open search |
| Alt+← | Back to the previous passage |
| Alt+Home | Home |
| Ctrl+← | Previous chapter |
| Ctrl+→ | Next chapter |
| Ctrl+R | Mark chapter as read |
| Ctrl+D | Bookmark verse (bookmark) |
| Ctrl+Shift+C | Copy verse with reference |
| Ctrl++ | Larger text |
| Ctrl+− | Smaller text |
| Ctrl+0 | Reset font size |
| Ctrl+B | Side panel on/off |
| Ctrl+T | Switch theme (light/dark) |
| F11 | Focus mode (text only) |
| Ctrl+G | Open verse overview |
| Ctrl+Shift+D | Open documents |
| Ctrl+Shift+O | Detach the current side panel |
| Ctrl+W | Close the current tab at the top (Reading stays) |

Several of these shortcuts also work while you're typing in a text field (for example Ctrl+K).

## 14.1a Highlighting in the reading text

| Action | Effect |
|---|---|
| Drag | select text (also across several verses) |
| Double-click / triple-click | select a word / the whole verse |
| Click on the verse number | highlight the whole verse (colors over the verse) |
| Plain click on highlighted words | colors for that highlight (recolor, ✕ to delete) |
| Ctrl+click | choose single verses |
| Shift+click | choose a range of whole verses |
| Ctrl+C | copy the selected text |
| Ctrl+Z | undo the last highlight |
| Alt+← / Alt+→ | back / forward through the passages you read last (so do the side buttons of the mouse) |
| Tab | switch between reading and the last tab (the dot on the tab sets which one) |
| Middle mouse button | quick marking on/off |
| In the Explorer: Ctrl+X, Ctrl+V, Del, Ctrl+Z, Ctrl+A | cut, paste, to the trash, undo, select all |
| Esc | clear the selection |

## 14.2 Fixed shortcuts in the editor and in lists

| Shortcut | Effect |
|---|---|
| Ctrl+B | Bold (in the document editor) |
| Ctrl+I | Italic (in the document editor) |
| Ctrl+0 / Ctrl+1 / Ctrl+2 / Ctrl+3 | Paragraph: normal text / heading 1 / 2 / 3 (in the document editor) |
| Ctrl+Shift+8 / +7 / +9 | Bulleted list / numbered list / quote (in the document editor) |
| Ctrl+Shift+− | Divider (in the document editor) |
| Ctrl+E | Switch between Write and Reading |
| Ctrl+S | Save immediately |
| Enter in a list | Continue the list |
| Enter | Add a new to-do or entry |
| Ctrl+Enter | Add a prayer request |
| Esc | Cancel (for example a sub-to-do, shortcut recording) |
| Delete | Clear the assignment of a shortcut (in Settings) |

> Ctrl+B means something different depending on where you are: in the document editor it makes text **bold**, otherwise it shows or hides the side panel. The same goes for every shortcut in this table: while the cursor is in the text of a document they belong to the editor, even if they do something else elsewhere in the program (for example Ctrl+0 for the font size). Selected text is wrapped in asterisks, pressing again takes them off.

## 14.3 Mouse

| Action | Effect |
|---|---|
| Click on a verse | Select the verse |
| Right-click on a verse | Verse menu |
| Click on an underlined word (Word study on) | Word study |
| Double-click on a graph node | Load more neighbors |
| Mouse wheel in the graph | Zoom |
| Drag a node | Move it |
| Drag an icon from the rail | Own window |
| Drag a document onto a folder/category | Move / set category |
| Drag the handle of a parallel column | Move the column |
| Drag the edge of the side panel | Change the width |

## 14.4 Custom shortcuts for column colors and more

The column colors of the Parallel view have no keyboard shortcut; they're found on the color button in the Parallel bar.

## 14.5 Reading with the arrow keys

| Key | Effect |
|---|---|
| ↑ / ↓ | Scroll the text; with a verse chosen: verse above / below |
| Shift + ↑ / ↓ | Choose several verses |
| ← / → | Previous / next chapter |
| Space | Show the colors for the chosen verses |
| In the colors: arrow keys, Enter, Esc | Pick a color, apply it, close |
| Tab / Shift+Tab (Materials) | Next / previous open file |
