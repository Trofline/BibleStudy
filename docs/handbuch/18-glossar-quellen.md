# 18. Glossar, Quellen und Lizenzen

## 18.1 Glossar

| Begriff | Bedeutung |
|---|---|
| **Advanced / Easy** | voller Funktionsumfang / aufgeräumte Oberfläche |
| **Akzentfarbe** | Hauptfarbe des Programms; die Hauptspalte im Parallel-Modus nutzt sie |
| **Aorist** | griechische Zeitform für eine einfache, punktuelle Handlung |
| **BDB** | Brown-Driver-Briggs, hebräisches Lexikon (1906, gemeinfrei) |
| **Backlink** | Rückverweis: ein Dokument, das auf das aktuelle zeigt |
| **Grundform (Lemma)** | die Wörterbuchform eines Wortes, zum Beispiel „gehen“ für „ging“ |
| **Grundtext** | der hebräische und griechische Originaltext |
| **Kantillation** | hebräische Akzentzeichen, die auch die Betonung angeben |
| **Kategorie** | farbiger Chip an einem Dokument, intern ein Tag `kat:Name` |
| **Konkordanz** | Verzeichnis aller Stellen, an denen ein Wort vorkommt |
| **Layout** | gespeicherte Fensteranordnung |
| **Lesezeichen** | gemerkter Vers ohne Notiz (früher „Merkliste“) |
| **LSJ** | Liddell-Scott-Jones, ausführliches griechisches Lexikon |
| **MCP** | Model Context Protocol, Schnittstelle, mit der KI-Programme BibleStudy bedienen |
| **Morphologie** | grammatische Form eines Wortes (Zeit, Fall, Person …) |
| **Ollama** | Programm für lokal laufende KI-Modelle |
| **Parallel** | mehrere Übersetzungen nebeneinander |
| **Plugin** | Erweiterung als eigener Prozess |
| **Querverweis** | Verbindung zwischen Versen |
| **Scripture alone** | Leitprinzip: der Bibeltext zuerst |
| **Strong-Nummer** | Nummer eines hebräischen (H) oder griechischen (G) Wortes nach James Strong |
| **Syntax** | Satzbau mit Rollen wie Subjekt, Verb, Objekt |
| **Tag** | Schlagwort an einer Markierung oder einem Dokument |
| **To-do** | Aufgabe fürs Studium, mit Teil-To-dos, Datum und Vers |
| **Vault** | Mappe (eine Datei) mit allem Persönlichen eines Projekts |
| **Wortstudie** | Anklicken eines Wortes mit Strong-Nummer für Grundtextwort und Vorkommen |

## 18.2 Quellen

Das Programm enthält keine Bibeltexte. Alles wird bei Bedarf von der Originalquelle geladen und ist unter *Einstellungen → Quellen und Lizenzen …* mit Herkunft und Lizenz aufgeführt. Die vollständige Liste steht in [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md). Beispiele für Quellen, die im Handbuch erwähnt werden:

- **Brown-Driver-Briggs** (1906, gemeinfrei), digitalisiert vom Open Scriptures Hebrew Lexicon Project, CC BY 4.0
- **Liddell-Scott-Jones**, bearbeitet von Tyndale House Cambridge (STEPBible), CC BY 4.0
- **Easton's Bible Dictionary** über Theographic
- **openthesaurus.de**, CC BY-SA 4.0 (deutsche Synonyme)
- **eBible.org**, World English Bible, gesprochen von Winfred W. Henson, gemeinfrei (Hörbibel)

Grundsatz bei neuen Quellen: nur gemeinfrei oder frei lizenziert (CC BY, CC BY-SA, CC0) von bekannten Stellen, nichts mit Einschränkung auf nichtkommerzielle Nutzung und nichts mit unklarer Lizenz.
