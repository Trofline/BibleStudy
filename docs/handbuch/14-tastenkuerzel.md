# 14. Tastenkürzel

Alle Kürzel in der ersten Tabelle lassen sich ändern (*Einstellungen → Tastenkürzel* oder der Knopf *Tastenkürzel* oben). Die Tabelle zeigt die **Standardbelegung**. Auf dem Mac gilt für „Strg“ in der Regel die Befehlstaste, je nach Einstellung deines Systems.

## 14.1 Änderbare Kürzel

| Kürzel | Wirkung |
|---|---|
| Strg+K | Gehe zu Stelle oder suchen |
| Strg+F | Suche öffnen |
| Alt+← | Zurück zur vorherigen Stelle |
| Alt+Pos1 | Startseite |
| Strg+← | Voriges Kapitel |
| Strg+→ | Nächstes Kapitel |
| Strg+R | Kapitel als gelesen markieren |
| Strg+D | Vers merken (Lesezeichen) |
| Strg+Umschalt+C | Vers mit Stelle kopieren |
| Strg++ | Schrift größer |
| Strg+− | Schrift kleiner |
| Strg+0 | Schriftgröße zurücksetzen |
| Strg+B | Seitenleiste ein/aus |
| Strg+T | Design wechseln (hell/dunkel) |
| F11 | Fokus-Modus (nur Text) |
| Strg+G | Vers-Übersicht öffnen |
| Strg+Umschalt+D | Dokumente öffnen |
| Strg+Umschalt+O | Aktuelles Seitenfenster auslagern |
| Strg+W | Aktuellen Reiter oben schließen (Lesen bleibt) |

Mehrere dieser Kürzel funktionieren auch, während du in einem Textfeld tippst (zum Beispiel Strg+K).

## 14.1a Beim Markieren im Lesetext

| Bedienung | Wirkung |
|---|---|
| Ziehen | Text auswählen (auch über mehrere Verse) |
| Doppelklick / Dreifachklick | Wort / ganzen Vers auswählen |
| Klick auf die Versnummer | ganzen Vers markieren (Farben über dem Vers) |
| Einfacher Klick auf markierte Wörter | Farben für diese Markierung (umfärben, ✕ löschen) |
| Strg+Klick | einzelne Verse wählen |
| Umschalt+Klick | Bereich ganzer Verse wählen |
| Strg+C | ausgewählten Text kopieren |
| Strg+Z | letzte Markierung rückgängig |
| Alt+← / Alt+→ | zurück / vorwärts durch die zuletzt gelesenen Stellen (ebenso die Seitentasten der Maus) |
| Tab | zwischen Lesen und dem letzten Reiter wechseln (der Punkt am Reiter legt fest, zu welchem) |
| Mittlere Maustaste | Schnellmarkieren ein/aus |
| Im Explorer: Strg+X, Strg+V, Entf, Strg+Z, Strg+A | ausschneiden, einfügen, in den Papierkorb, rückgängig, alles wählen |
| Esc | Auswahl aufheben |

## 14.2 Feste Kürzel im Editor und in Listen

| Kürzel | Wirkung |
|---|---|
| Strg+B | Fett (im Dokument-Editor) |
| Strg+I | Kursiv (im Dokument-Editor) |
| Strg+0 / Strg+1 / Strg+2 / Strg+3 | Absatz: normaler Text / Überschrift 1 / 2 / 3 (im Dokument-Editor) |
| Strg+Umschalt+8 / +7 / +9 | Aufzählung / nummerierte Liste / Zitat (im Dokument-Editor) |
| Strg+Umschalt+− | Trennlinie (im Dokument-Editor) |
| Strg+E | zwischen Schreiben und Lesen umschalten |
| Strg+S | sofort speichern |
| Enter in einer Liste | Liste fortführen |
| Enter | neues To-do bzw. Eintrag hinzufügen |
| Strg+Enter | Gebets-Anliegen hinzufügen |
| Esc | abbrechen (zum Beispiel Teil-To-do, Kürzel-Aufnahme) |
| Entf | Belegung eines Kürzels löschen (in den Einstellungen) |

> Strg+B bedeutet je nach Ort etwas anderes: Im Dokument-Editor macht es Text **fett**, sonst blendet es die Seitenleiste ein oder aus. Dasselbe gilt für alle Kürzel dieser Tabelle: Steht die Schreibmarke im Text eines Dokuments, gehören sie dem Editor, auch wenn sie sonst im Programm etwas anderes tun (zum Beispiel Strg+0 für die Schriftgröße). Markierter Text wird mit Sternchen umschlossen, ein zweiter Druck nimmt sie wieder weg.

## 14.3 Maus

| Aktion | Wirkung |
|---|---|
| Klick auf einen Vers | Vers wählen |
| Rechtsklick auf einen Vers | Vers-Menü |
| Klick auf unterstrichenes Wort (Wortstudie an) | Wortstudie |
| Doppelklick auf einen Graphknoten | mehr Nachbarn laden |
| Mausrad im Graphen | zoomen |
| Knoten ziehen | verschieben |
| Symbol aus der Leiste ziehen | eigenes Fenster |
| Dokument auf Ordner/Kategorie ziehen | verschieben / Kategorie setzen |
| Punkt einer Parallel-Spalte ziehen | Spalte verschieben |
| Rand der Seitenleiste ziehen | Breite ändern |

## 14.4 Eigene Kürzel für Spaltenfarben und mehr

Die Spaltenfarben der Parallel-Ansicht haben kein Tastenkürzel; sie liegen am Farb-Knopf der Parallel-Leiste.
