# BibleStudy – Roadmap

Freie, quelloffene Bibelstudien-Software (C#, Avalonia). Nur Quellen mit freier Lizenz; die Lizenz wird je Übersetzung angezeigt.

## Phase 1 – Orientierung & Grundlagen
- [x] Startseite mit Buch-/Kapitelraster (Fortschritt je Buch)
- [x] Zurück-Knopf (Navigationsverlauf)
- [x] Gelesen markieren (einzeln und massenhaft)
- [x] Offline-Download je Übersetzung
- [x] Einstellungen (gespeichert), Hilfe, Info (Maße, Gewichte, Abkürzungen)

## Phase 2 – Persönliches Wissen (Vaults)
- [x] Mehrere Vaults (wie Obsidian), jeder eine eigene Datei
- [x] Markierungen innerhalb von Versen (Wörter) und ganze Verse, Farben (Vorschläge + eigene)
- [x] Sammlung mit Notiz, Ordnern, Tags (Auto-Tag Buchname), Schnellsprung, Farbe ändern
- [x] Warteschlange (Queue) und To-Do-Liste
- [ ] Dokumente verlinken, eigene Wissensdatenbank

## Phase 3 – Claude-Anbindung
- [x] MCP-Server (23 Werkzeuge): Claude kann lesen, suchen, markieren, navigieren, das Programm steuern
- [x] KI-Fenster über die lokale Claude-Installation (Abo, kein API-Schlüssel)

## Phase 4 – Querverweise & Visualisierung
- [x] Querverweise im Text (Chips unter den Versen, Vorschau beim Überfahren)
- [x] Graph neben dem Text (Fäden von jedem Vers zu den Büchern)
- [x] Netzwerk-Graph mit Einstellungen (Richtung, Knotenzahl, Zentrum wechseln)
- [x] Bogen-Ansicht der ganzen Bibel (Buchfilter, Stärke)
- [x] Fußnoten anklickbar

## Phase 5 – Studium
- Wort-/Satzprüfung Hebräisch/Griechisch (Interlinear, Lexikon)
- Erweiterte Suche, Parallelansicht synchronisiert (inkl. Grundtext)
- Vorlesen, Karte (Orte, Wege)
- Export/Import (Einstellungen, Verse, Vaults)
