# Sicherheit / Security

## Deutsch

Hast du eine Sicherheitslücke in BibleStudy gefunden? Bitte melde sie **nicht** als öffentliches Issue, sondern privat:

1. Öffne den Reiter **Security** dieses Repositorys.
2. Wähle **Report a vulnerability** und beschreibe das Problem (Version, Schritte zum Nachstellen, mögliche Folgen).

Ich antworte so schnell ich kann und gebe Bescheid, sobald ein Update bereitsteht. Unterstützt wird immer die **neueste Version**; sie ist auf der Seite „Releases“ zu finden.

Gut zu wissen: BibleStudy arbeitet offline, braucht kein Konto und sendet keine Daten an einen eigenen Server. Das gemeinsame Studium ist Ende-zu-Ende verschlüsselt und läuft direkt zwischen den Teilnehmern.

## English

Found a security problem in BibleStudy? Please do **not** open a public issue. Report it privately:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability** and describe the problem (version, steps to reproduce, possible impact).

I will answer as soon as I can and tell you when an update is ready. Only the **latest release** is supported (see “Releases”).

Good to know: BibleStudy works offline, needs no account and sends no data to a server of its own. Studying together is end-to-end encrypted and runs directly between the participants.
