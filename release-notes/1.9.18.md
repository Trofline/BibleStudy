## New in 1.9.18
**Kind of update:** Bugfix
- **[Feature]** **No sync notice on closing when nothing changed:** if nothing new was done since the last synchronisation with the phone, closing no longer waits for the phone or shows the notice.
- **[Fix]** The Android app is part of every release again (1.9.15–1.9.17 had none).
- **[Fix]** The tab row scrolls when it is full (the last tab and + ran off the edge).
- **[Fix]** A Bible reference without a book takes the nearest book before it (e.g. Dan 2,21; 4,14).
- **[Fix]** A range into the next chapter counts for all its verses in searches and backlinks.
- **[Fix]** Page numbers in Word and OpenDocument files count every page break and empty pages.
- **[Fix]** A document shared in a group brings its pictures along.
- **[Fix]** A picture name inside a Word/OpenDocument/PowerPoint file can no longer write outside the picture folder.
- **[Fix]** The marks filters (folder, tags) no longer cut their text.
- **[Fix]** Saved dates use one fixed format on every device.
- **[Fix]** Microphone, speaker and camera problems can no longer close the program.
- **[Fix]** No links to chapter or verse 0; e-Sword names with special characters are quoted.

**iPhone:** update in SideStore (Sources → pull down → My Apps → Update). **Android:** the app updates itself (on 1.9.14 or older, install the APK from this release once).
