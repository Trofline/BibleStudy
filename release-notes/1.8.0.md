## New in 1.8.0
**Kind of update:** Feature, Improvement, Bug fix
- **[Feature]** **Search all materials:** A field above the folder tree searches every file of the materials folder at once (case and accents do not matter). The hits are listed by file with a piece of text, and a click opens the file at exactly that place.
- **[Feature]** **Find in a file (Ctrl+F):** Ctrl+F searches the open file of the materials; Enter and Shift+Enter go from place to place, and the count shows where you are.
- **[Feature]** **Verse preview:** Resting the mouse on a Bible reference in the materials shows the verse in your translation, without leaving the file.
- **[Feature]** **Your materials in the verse overview:** When you click a verse, the overview shows "In your materials": every file that mentions it (also inside a passage such as Rom 8:26-30), with a piece of text and a click to open it there.
- **[Feature]** **Marks and notes in materials:** Select text in a file and right-click to mark it in a color, with a note if you like. The note stands below the paragraph, and "My marks" lists them all. The file itself is never changed: marks live in your vault and in your backups, and are found again when the file changes or moves.
- **[Feature]** **Projector view:** Verses (right-click a verse, or Ctrl+K) or pieces of the materials show large and calm on a second screen, light on dark. Arrow keys go on and back, B makes the screen black, Esc closes; the status bar shows what is on the projector.
- **[Feature]** **Program for the timer:** Write the parts of a Bible study with their time (song, prayer, Bible study …) and start them as a program. Beside the clock you see which part is on and how long is left; when a part is over, the next one begins with a short tone.
- **[Feature]** **Handouts:** Printing a document (Export → Print / PDF) makes a designed handout. Choose one of eight looks that differ in layout as well as color (Classic, Modern, Plain to save ink, Elegant with a large initial, Church newsletter, Newspaper in two columns, Large print, Nature) and a name for the head. The Bible references get small numbers that lead to the verses at the end, shown as cards (in two columns if you like); questions stand out in a box; lined space for notes can follow. A4 pages with page numbers, a preview in the browser, and the HTML export gets the same look.
- **[Feature]** **One export window:** HTML and Markdown now open the same window as printing. HTML gets the chosen look and a preview in the browser; Markdown lets you put the verses in their own file, as quotes under the text or leave them out, add a YAML head for Obsidian, and shows the text before saving.
- **[Improvement]** **Reading position in materials:** Every file opens where you last read it, also after a restart.
- **[Bug fix]** References to 4. Mose and 5. Mose and the short forms Hebr, Koh, Hi, Esr, Am, Obd, Mi and Zef are now recognized.
