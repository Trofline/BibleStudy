## New in 1.6.11
**Kind of update:** Bug fix, New feature, Improvement
- **[New feature]** **Better import with a check for an AI:** After an import, BibleStudy looks for typical faults (left-over markers, split words, empty verses, missing verses) and can save a report with rules and the places found. Give it to an AI together with your source file and import the corrected USFM file again.
- **[New feature]** **Headings of imported Bibles:** Section headings of a PDF or USFM translation (such as in Schlachter 2000) are imported and shown in front of their verse.
- **[New feature]** **Show headings (Settings):** Choose all headings, only your own, only the translation's, your own with the translation's only where you have none, or none.
- **[New feature]** **Rename a vault:** Next to the vault list; an export now keeps the vault name and the sub-mark color, and the import uses them.
- **[New feature]** **Reading tab keys:** Typing a number jumps to that verse; Page Up / Page Down scroll the text.
- **[Improvement]** **Marks follow the translation:** Marks and sub-marks also show in other translations.
- **[Improvement]** Changing the sub-mark color recolors existing sub-marks.
- **[Bug fix]** PDF import: "HERR" no longer turns into "H", stray letters like "d aß" are gone.
- **[Bug fix]** HTML import: Strong numbers and edition markers (G6137 NA/G1782 TR) no longer end up in the text.
