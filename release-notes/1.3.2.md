## Neu in 1.3.2
- **Mac:** BibleStudy ist jetzt eine richtige App (`BibleStudy.app`) mit Logo und eigenem Namen im Dock und in der Menüleiste. Nach der einmaligen Einrichtung startest du sie per Doppelklick, ohne Terminal. (Die Einrichtung steht in README-macOS.txt; nicht jedes macOS ist getestet.)
- **Zusammen studieren:** Der Einladungscode enthielt bisher nur die Adresse aus dem eigenen Netz, nicht die von außen sichtbare. Dadurch ging die Verbindung nur im selben Netzwerk und auch dort oft nicht. Beide Adressen sind jetzt im Code (neue Codes nötig). Beim Warten zeigt das Programm den Verbindungsstatus, und beim Scheitern nennt es mögliche Gründe (Firewall, Mac-Freigabe „Lokales Netzwerk“) samt technischen Angaben.
- **Zusammen-Reiter:** Er erscheint jetzt schon beim ersten Klick, nicht erst beim zweiten.
- **Startseite:** Das Haus-Symbol funktioniert jetzt auch aus dem Einstellungen-Reiter und anderen Reitern.

## New in 1.3.2
- **Mac:** BibleStudy is now a real app (`BibleStudy.app`) with its logo and its own name in the Dock and the menu bar. After the one-time set-up you start it with a double-click, without Terminal. (The set-up is described in README-macOS.txt; not every macOS version is tested.)
- **Study together:** the invitation code used to contain only the address from the own network, not the one visible from outside. So the connection only worked in the same network, and often not even there. Both addresses are now in the code (new codes are needed). While waiting, the program shows the connection state, and when it fails it names possible reasons (firewall, the Mac permission “Local Network”) with technical details.
- **Together tab:** it now appears at the first click, not only at the second.
- **Home page:** the house icon now also works from the settings tab and other tabs.
