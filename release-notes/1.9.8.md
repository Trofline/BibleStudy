## New in 1.9.8
**Kind of update:** Feature, Bug fix
- **[Feature]** **Reading progress syncs too:** chapters read on one device show as read on the other; "unread" travels as well.
- **[Feature]** **Sync button:** "Sync" next to the version number at the bottom (PC) and at the top of the Tools menu (phone).
- **[Feature]** While both apps are open, devices sync every 20 seconds besides a few seconds after each change.
- **[Bug fix]** "Sync now" also reaches an iPhone (it never answers the network call-out).
- **[Bug fix]** Reading progress from another device was taken over only once per start.

**iPhone:** add the SideStore source `https://trofline.github.io/BibleStudy/sidestore.json` (or install the `.ipa` below with SideStore). **Android:** install the `.apk` below once if you have 1.9.6 or older; from 1.9.7 the app updates itself.
