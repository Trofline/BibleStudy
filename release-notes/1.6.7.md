## Neu in 1.6.7
**Art dieses Updates:** Neue Funktionen
- **[Neu]** **Schnell-Updates:** Künftig lädt ein Update nur noch die geänderten Dateien, meist wenige MB statt rund 200 MB, auch wenn du mehrere Versionen ausgelassen hast. Das gilt für Windows, Linux und macOS; auf Linux und macOS installiert sich ein Update damit erstmals direkt im Programm. Startet die neue Version nicht, kommt die alte automatisch zurück. Dieses eine Update lädt noch einmal das ganze Paket.
- **[Neu]** **Querverweise im Zusammenhang:** Rechtsklick auf einen Querverweis → *Im Zusammenhang in neuem Reiter öffnen* zeigt das ganze Kapitel mit hervorgehobenen Versen, dein Lesefenster bleibt, wo es ist. Mit *In eigenem Fenster* oder durch Herausziehen des Reiters liest du beide Stellen nebeneinander. Unter Einstellungen → Lesen und Verhalten kann auch der normale Klick so öffnen. Vorschlag aus der Community, danke!
- **[Geändert]** **„Gelesen“ gilt für alle Vaults:** Der Lesefortschritt hängt nicht mehr an einem Vault. Beim ersten Start werden die Stände aller Vaults zusammengeführt, es geht nichts verloren. Ein Gast-Vault behält seine eigene Liste.

## New in 1.6.7
**Kind of update:** New features
- **[New]** **Quick updates:** From now on an update downloads only the changed files, usually a few MB instead of about 200 MB, even if you skipped several versions. This works on Windows, Linux and macOS; on Linux and macOS an update now installs right in the program for the first time. If the new version does not start, the old one comes back automatically. This one update still downloads the whole package.
- **[New]** **Cross references in context:** Right click a cross reference → *Open in context in a new tab* shows the whole chapter with the verses highlighted, while your reader stays where it is. With *In its own window* or by dragging the tab out you read both passages side by side. Under Settings → Reading and behavior a plain click can open it this way too. Suggested by the community, thank you!
- **[Changed]** **"Read" counts for all vaults:** Reading progress no longer depends on a vault. On the first start the progress of all vaults is merged, nothing is lost. A guest vault keeps its own list.
