# Third-party notices and data sources

BibleStudy's own code is MIT-licensed (see LICENSE). The program ships **no Bible text, commentary or dataset**.
Everything below is downloaded at the user's request from its original source, or imported by the user from their own files.
The license of each translation or commentary is shown in the program next to the text.

## User-imported files

Translations that the user imports from their own files (for example a private Elberfelder CSV) stay on the user's computer,
are marked as "local import, private use only", and are never uploaded or redistributed by the program.
